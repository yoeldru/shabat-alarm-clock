# שעון מעורר לשבת

אפליקציית שעון מעורר לאנדרואיד (Kotlin).

- מצלצל גם כשהטלפון על שקט / רטט, וגם כשהמסך כבוי (ערוץ השמע של שעון מעורר + `setAlarmClock`)
- אורך הצלצול בשניות — אחריו הצלצול נפסק מעצמו
- ימים חוזרים לבחירה, או שעון חד-פעמי
- צליל מהטלפון או קובץ שמע משלך
- צליל / צליל+רטט / רטט בלבד, עוצמה, עוצמה עולה בהדרגה
- נודניק — הפעלה/ביטול ואורך בדקות
- **מצב שבת**: אין כפתורי כיבוי ונודניק — הצלצול נמשך את הזמן שנקבע ונפסק מעצמו
- כפתור שיתוף עם קישור להורדה
